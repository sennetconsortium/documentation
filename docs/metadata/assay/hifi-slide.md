# HiFi-Slide Metadata Attributes

The attributes shown here have been colleced for HiFi-Slide data, available from the [HuBMAP Search and Entity APIs](/apis) at ```Dataset.metadata.<attribute>```.<br />
These attributes are harmonized across all versions of the HiFi-Slide metadata specifications. See the latest version of the [HiFi-Slide Metadata Specifications](https://hubmapconsortium.github.io/ingest-validation-tools/hifi-slide/current/) for the schema and directory structure needed when ingesting Segmentation Mask metadata.
&nbsp;

| data_path | <i class="fa-solid fa-font" title="Textfield" aria-label="Textfield"></i> | The top level directory containing the raw and/or processed data.
