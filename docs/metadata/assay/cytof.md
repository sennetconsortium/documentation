# CyTOF Metadata Attributes

The attributes shown here have been colleced for CyTOFF data, available from the [HuBMAP Search and Entity APIs](/apis) at ```Dataset.metadata.<attribute>```.<br />
These attributes are harmonized across all versions of the CyTOFF metadata specifications. See the latest version of the [CyTOFF Metadata Specifications](https://hubmapconsortium.github.io/ingest-validation-tools/cytof/current/) for the schema and directory structure needed when ingesting Segmentation Mask metadata.
&nbsp;

| parent_sample_id <span class="requiredMark">*</span> | <i class="fa-solid fa-font" title="Textfield" aria-label="Textfield"></i> | The unique identifier from HuBMAP or SenNet for the sample (such as a block, section, or suspension) used to perform the assay. | source_storage_duration_value <span class="requiredMark">*</span> | <i class="fa-solid fa-font" title="Textfield" aria-label="Textfield"></i> | The length of time the sample was stored prior to processing it. | source_storage_duration_unit <span class="requiredMark">*</span> | <i class="fa-solid fa-circle-nodes" title="Allowable Value" aria-label="Allowable Value"></i> | The unit of measurement used to specify the source storage duration value. | contributors_path <span class="requiredMark">*</span> | <i class="fa-solid fa-font" title="Textfield" aria-label="Textfield"></i> | The name of the file containing the ORCID IDs for all contributors to this dataset. Example: ./contributors.csv |  |
| data_path <span class="requiredMark">*</span> | <i class="fa-solid fa-font" title="Textfield" aria-label="Textfield"></i> | The top-level directory containing the raw and/or processed data. If there are multiple directory levels, use the format "./TEST001-RK/Run1/Pass2", where "Pass2" is the subdirectory where the single dataset's data is stored. | number_of_mass_channels <span class="requiredMark">*</span> | <i class="fa-solid fa-font" title="Textfield" aria-label="Textfield"></i> | The number of mass channels used to measure the expression of markers in single cells. Example: 45 |  |

| is_fcr_blocking_applied <span class="requiredMark">*</span> | <i class="fa-solid fa-circle-dot" title="Radio" aria-label="Radio"></i> | Indicates whether a reagent has been added to the staining procedure to block the binding of antibodies to Fc receptors (FcRs) on cells.
